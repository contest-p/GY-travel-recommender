🌍 AI 여행 추천 프로그램
1. 프로그램 개요
사용자가 여행 날짜를 입력하면 LLM과 지도 API를 활용해 최적의 여행지를 추천해 주는 프로그램입니다. 추천 지역, 날씨, 축제 정보와 함께 해당 지역의 맛집 리스트를 검색하여 마크다운 형태의 깔끔한 여행 리포트를 자동 생성합니다.

2. 설치 방법
프로그램을 실행하기 위해 필요한 라이브러리들을 설치해야 합니다. 터미널에 아래 명령어를 입력해 주세요.

Bash
pip install -r requirements.txt
3. .env 설정 방법
API 키를 안전하게 관리하기 위해 환경 변수 파일을 설정해야 합니다.

프로젝트 최상단에 .env 파일을 생성합니다.

발급받은 API 키를 아래와 같이 입력하여 저장합니다.

Plaintext
GEMINI_API_KEY="본인의_제미나이_API_키"
KAKAO_REST_API_KEY="본인의_카카오_REST_API_키"
4. 실행 예시
터미널에 아래와 같이 날짜 옵션(-date)과 함께 YYYY-MM-DD 형식으로 날짜를 입력하여 실행합니다.

Bash
python main.py -date "2024-12-25"
5. 결과물 위치 안내
프로그램 실행이 완료되면 프로젝트 폴더 내에 results/ 폴더가 생성됩니다. 해당 폴더 안에서 다음 두 가지 파일을 확인할 수 있습니다.

..._data.json: 원본 데이터와 검색 결과가 저장된 파일입니다.

..._travel_plan.md: 최종적으로 예쁘게 정리된 여행 리포트 문서입니다.

6. API 키 보안 주의사항
⚠️ 경고: API 키가 포함된 .env 파일은 절대 깃허브(GitHub) 등 외부에 공개된 저장소에 업로드하면 안 됩니다.

키가 유출될 경우 악용되거나 과금 문제가 발생할 수 있으므로, 반드시 .gitignore 파일이 제대로 적용되어 .env 파일이 업로드되지 않도록 주의해 주세요.
